# Retourrbezel
Vous cherchez à savoir comment faire un retour Bezel ? La réponse est directe : Bezel n'accepte aucun retour après réception de la montre. Une fois le colis livré et signé, aucun échange ni remboursement n'est possible. En revanche, une annulation avec remboursement est envisageable avant la mise en livraison.
